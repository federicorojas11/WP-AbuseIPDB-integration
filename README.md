A comprehensive WordPress security plugin that integrates with AbuseIPDB to protect your website from malicious IPs, spam, and other threats.

## Description

**WP AbuseIPDB Integration** provides a full suite of security features to protect your WordPress site. By leveraging the vast database of malicious IP addresses from AbuseIPDB, this plugin can automatically detect and block threats before they reach your website.

### Key Features:

*   **Automatic IP Analysis:** Checks incoming IP addresses against the AbuseIPDB database and blocks those with a high abuse score.
*   **Customizable Security Rules:** Fine-tune the security rules to match your needs. You can decide what events to monitor and what actions to take.
*   **Country Blocking:** Block or allow visitors from specific countries.
*   **Detailed Detections Log:** A comprehensive log of all detected threats, including IP address, threat level, country of origin, and more.
*   **Dashboard with Statistics:** An intuitive dashboard that provides an overview of your site's security status and recent threats.
*   **Auto-reporting of Malicious IPs:** Automatically report malicious IPs to AbuseIPDB to contribute to a safer internet for everyone.

## Installation

1.  Upload the `wp-abuseipdb-integration` folder to the `/wp-content/plugins/` directory.
2.  Activate the plugin through the 'Plugins' menu in WordPress.
3.  Go to the **AbuseIPDB > Configuration** page and enter your AbuseIPDB API key.
4.  Configure the security rules and other settings to your liking.

## Frequently Asked Questions

**Do I need an AbuseIPDB API key?**

Yes, you need an API key from [AbuseIPDB](https://www.abuseipdb.com/) to use this plugin. The plugin will not work without it.
